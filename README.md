# GapLift 🚀

GapLift is an AI-powered Skill Gap Analyzer built with the MERN stack and Gemini API. It compares resumes with job descriptions, identifies missing skills, generates personalized technical and behavioral interview questions, and creates a customized learning roadmap to help users prepare for their target roles.

## ✨ Features
- 📄 Resume Upload
- 💼 Job Description Analysis
- 🤖 Gemini AI Integration
- 📊 Skill Gap Detection
- 🎯 Personalized Learning Roadmap
- 💬 Technical & Behavioral Interview Questions
- 🔐 User Authentication
- 📱 Responsive UI

## 🛠️ Tech Stack
- React.js
- Node.js
- Express.js
- MongoDB
- Gemini API
- HTML, CSS, SCSS, JavaScript
